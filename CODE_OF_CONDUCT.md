# Code of Conduct

CoachDoku adopts the Contributor Covenant, version 2.1, as our Code of Conduct.

The full text is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

Conduct concerns should be reported to the maintainers via the contact information in the project README. The project does not yet have a dedicated email; concerns can be raised privately by opening a GitHub issue marked as confidential or contacting Mihai directly.

All complaints will be reviewed and investigated promptly and fairly. Maintainers are obligated to respect the privacy and security of the reporter of any incident.
